# راهنمای نصب ریلای تلگرام روی کلادفلر (Cloudflare Workers)

اپراتورهای ایرانی، آدرس `api.telegram.org` را مسدود کرده‌اند؛ به همین دلیل سرور Polaris بدون پروکسی نمی‌تواند به بات تلگرام پیام بدهد. راه‌حل استاندارد و رایگان این است که یک **Worker روی کلادفلر** بسازیم که مثل یک تکرر (relay) شفاف عمل کند: همه درخواست‌ها را با همان مسیر و همان بدنه به تلگرام می‌فرستد و جواب را عیناً برمی‌گرداند. کلادفلر در ایران فیلتر نیست و پلن رایگان آن برای این کار کاملاً کافی است (۱۰۰هزار درخواست در روز).

فایل آماده Worker در `docs/telegram-proxy-worker.js` است — فقط کپی کنید.

## گام ۱ — ساخت حساب و ورود

1. به [dash.cloudflare.com](https://dash.cloudflare.com) بروید و با یک ایمیل ثبت‌نام کنید (رایگان).
2. نیازی به انتقال دامنه یا تغییر DNS نیست؛ فقط از بخش Workers استفاده می‌کنیم.

## گام ۲ — ساخت Worker

1. از منوی کناری وارد **Workers & Pages** شوید.
2. روی **Create** (ساخت) کلیک کنید و گزینه **Create Worker** را بزنید.
3. یک نام دلخواه بگذارید، مثلاً `polaris-telegram-relay`، و روی **Deploy** بزنید تا نسخه اولیه ساخته شود.
4. روی **Edit code** (ویرایش کد) کلیک کنید.
5. تمام کد پیش‌فرض را پاک کنید و **کل محتوای فایل `docs/telegram-proxy-worker.js`** را جای آن بچسبانید.
6. دوباره **Deploy** بزنید.

## گام ۳ — گرفتن آدرس Worker

بعد از Deploy، بالای صفحه آدرسی شبیه این نمایش داده می‌شود:

```
https://polaris-telegram-relay.your-name.workers.dev
```

این همان «آدرس ریلای» است — بدون `/` آخر. آن را کپی کنید.

برای اطمینان، در مرورگر این آدرس را باز کنید:

```
https://polaris-telegram-relay.your-name.workers.dev/bot<TOKEN>/getMe
```

(به‌جای `<TOKEN>` توکن بات خودتان را بگذارید.) اگر جواب JSON با اطلاعات بات برگشت، ریلای درست کار می‌کند.

## گام ۴ — ثبت آدرس در Polaris

1. وارد پنل کارگاه شوید: **تنظیمات ← اطلاع‌رسانی**.
2. در فیلد **«آدرس ریلای کلادفلر»** آدرس Worker را بچسبانید.
3. ذخیره کنید و با دکمه «ارسال تست» صحت اتصال را بررسی کنید.

از این به بعد همه پیام‌های تلگرام (اطلاع سفارش جدید، پیام تست، گزارش پشتیبان‌گیری و…) از مسیر این Worker ارسال می‌شوند و دیگر به پروکسی نیاز نیست. اگر قبلاً «آدرس پروکسی HTTP(S)» پر کرده بودید می‌توانید خالی‌اش کنید؛ ریلای جای آن را می‌گیرد.

## نکته‌ها و عیب‌یابی

- **ترتیب اولویت:** اگر هم «ریلای» و هم «پروکسی» پر باشند، ریلای مقدم است.
- **هزینه:** پلن رایگان کلادفلر برای این کاربرد عملاً تمام‌نشدنی است.
- **امنیت:** Worker فقط تکرر است؛ توکن بات در آن ذخیره نمی‌شود. آدرس Worker مخفی نیست، اما چون توکن بات داخل URL درخواست‌هاست، در عمل بهتر است آدرس را فقط داخل تیم به اشتراک بگذارید. اگر سوءاستفاده مشکوک دیدید، در کلادفلر یک Worker جدید با نام دیگر بسازید و آدرس قبلی را باطل کنید.
- **خطای 403/1010 در آدرس workers.dev:** بعضی شبکه‌های داخلی آدرس `*.workers.dev` را محدود کرده‌اند؛ با یک دامنه شخصی روی کلادفلر (Custom Domain برای Worker) مشکل حل می‌شود.
- **به‌روزرسانی:** اگر کد Worker را بعداً عوض کردید، فقط در کلادفلر Deploy مجدد بزنید — نیازی به تغییر چیزی در Polaris نیست.

## جایگزین: خط فرمان (Wrangler)

اگر با ترمینال راحت‌ترید:

```bash
npm install -g wrangler
wrangler login
# فایل docs/telegram-proxy-worker.js را در یک پوشه خالی ذخیره کنید
wrangler deploy docs/telegram-proxy-worker.js --name polaris-telegram-relay
```

جواب دستور، همان آدرس نهایی است.
